# Ahadh Jamal — Portfolio prototype

A responsive, static portfolio concept built with plain HTML, CSS and JavaScript. Open `index.html` directly or serve this folder from any static host. No build step or dependency install is needed.

## Visual direction

The page follows the supplied reference with a name-led cinematic hero, compact About and metrics panel, and a tight three-column project gallery. The project covers and NuVora store views are local images; the Creative Lab keeps a cooler, instrument-panel treatment. Project content, capabilities and lab notes are grouped at the top of `script.js` for quick editing.
